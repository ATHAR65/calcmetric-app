## Execution rules (from what's worked so far)
1. **Slug ≠ blog slug.** Never reuse the same slug for calc + blog (caused our 2 "Crawled - not indexed" pages). Calculator = `/calculators/x-calculator`, blog = a *different intent* title, e.g. `/blog/how-x-deduction-works-2026`.
2. Every calc: QuickAnswer box, worked example with real numbers, 5+ FAQ with schema, HowTo schema, 2–3 internal links inside its cluster, dateModified + LAST_CONTENT_UPDATE.
3. OBBBA calcs: cite IRS newsroom page as source; phase-outs must match IRS figures exactly.
4. Marketplace calcs: verify each platform's current fee page at build time (fees change quarterly); cite the official fee page.
5. Build order: Tier 1 (5 calcs) → Tier 2 (10) → Tier 3 (10) → Tier 4 (2). Tier 1+2 = 15 winnable pages in the first pass; ship Tier 1 in one release for the OBBBA cluster boost.
